# 12-Week Execution Plan

## Overview

This plan is designed for 5–8 hours per week of business development. It runs parallel to:

- B2B contract / Lead Data Engineer job search
- Any existing work commitments

Each week has specific focus areas, actions, and targets.

---

## Weekly Time Budget

| Activity                          | Hours/Week |
| --------------------------------- | ---------- |
| Outreach (messages, follow-ups)   | 2–3        |
| Content (LinkedIn posts)          | 1          |
| Calls (discovery, networking)     | 1–2        |
| Research (target list, companies) | 1          |
| Admin (tracking, proposals)       | 0.5–1      |
| **Total**                         | **5.5–8**  |

## Balancing with B2B Job Search

### Weekly Time Split

| Phase      | Consulting BD | B2B Search |
| ---------- | ------------- | ---------- |
| Weeks 1–4  | 60%           | 40%        |
| Weeks 5–8  | 50%           | 50%        |
| Weeks 9–12 | 60%           | 40%        |

### Decision Points

- **If B2B offer comes**: Evaluate flexibility, accept if good fit
- **If consulting engagement starts**: Pause B2B search
- **If neither progressing**: Increase B2B search intensity
- **If both progressing**: Choose based on income stability vs growth
