# Client Acquisition Plan

## Overview

This plan is designed for a solo founder with 5–8 hours per week available for business development. It balances:

1. **Immediate income**: B2B contract / Lead Data Engineer search
2. **Consulting pipeline**: Architecture Audit and Fractional Lead opportunities
3. **Partner channel**: Software houses, consultancies, recruiters

Build visibility and start conversations without relying on warm contacts.

| Activity                               | Weekly Target |
| -------------------------------------- | ------------- |
| Original posts                         | 3             |

| Connection requests (after engagement) | 10–15         |

**Content focus:**

- Databricks cost optimization tips
- Quick wins for Spark performance
- Data platform architecture insights
- "Mistake I fixed" stories

**Where to find target profiles:**

- Search: "Head of Data" + scale-up companies
- Search: "CTO" + 50-500 employee companies

### Strategy B: Cold Outreach (Parallel)

**Target search criteria:**

- Location: EU (start with DACH, UK, Nordics)

**Cold outreach volume:**

- 5–10 personalized messages per week
- Research company before messaging
- Reference specific pain point (Databricks costs, platform chaos)

## Phase 5: Conversion (Ongoing)

### Conversion Path

```
Connection/Outreach → Reply → Discovery Call → Qualification → Proposal → Paid Engagement
```

### Discovery Call Structure

1. **Understand situation** (10 min)
   - What's your current data setup?
   - What's working, what's not?
   - What triggered this conversation?

2. **Understand goals** (10 min)
   - What does success look like?
   - What's the timeline?
   - What's the budget range?

3. **Share approach** (10 min)
   - How seniuts works
   - Relevant experience
   - Typical engagement path

4. **Next steps** (5 min)
   - Summarize fit
   - Propose next step (Audit proposal)
   - Agree timeline

### Qualification Criteria

| Criteria       | Good Fit                  | Poor Fit               |
| -------------- | ------------------------- | ---------------------- |
| Budget         | Has budget or can approve | No budget, "exploring" |
| Timeline       | Next 1–3 months           | "Someday"              |
| Decision maker | Talking to decision maker | Talking to researcher  |
| Problem        | Clear pain point          | Vague interest         |
| Fit            | Data platform scope       | Pure analytics / BI    |

### Proposal Structure

1. Summary of situation and goals
2. Proposed approach (Audit scope)
3. Deliverables
4. Timeline
5. Investment
6. Next steps

### Success Criteria

- Discovery calls lead to proposals (50%+)
- Proposals lead to paid work (30%+)
- First Architecture Audit completed

## B2B Contract Search Balance

### Parallel Activities

- Continue applying for Lead Data Engineer / Technical Data Lead roles
- Use seniuts as professional credibility
- Track B2B opportunities in same spreadsheet
- Prioritize roles that allow consulting flexibility

### Decision Rules

| Situation                               | Action                 |
| --------------------------------------- | ---------------------- |
| Good B2B offer, no consulting pipeline  | Accept B2B             |
| Consulting pipeline building, B2B offer | Evaluate flexibility   |
| Consulting engagement starting          | Pause B2B search       |
| Between engagements                     | Activate both channels |
