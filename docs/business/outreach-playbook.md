# Outreach Playbook

## Overview

This playbook contains message templates for different outreach scenarios. All messages are designed to be:

- Professional but human
- Concise (under 150 words for initial messages)
- Clear in the ask
- Not spammy or desperate
- Ready to copy and adapt

## Tone Guidelines

| Do                        | Don't                               |
| ------------------------- | ----------------------------------- |
| Be concise                | Write long paragraphs               |
| Be specific               | Use vague buzzwords                 |
| Be human                  | Sound like a template               |
| Have a clear ask          | Leave the next step unclear         |
| Follow up once or twice   | Send multiple aggressive follow-ups |
| Accept "no" gracefully    | Be pushy or desperate               |
| Personalize when possible | Mass-send identical messages        |

## Message Checklist

Before sending any outreach message:

- [ ] Is it under 150 words?
- [ ] Is there a clear ask or next step?
- [ ] Is it personalized to the recipient?
- [ ] Does it sound human, not robotic?
- [ ] Would I respond to this message?
- [ ] Is my contact info included?
