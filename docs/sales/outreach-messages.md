# 12. Outreach principles

Do:

- keep messages short
- personalize the first line if possible
- focus on the client’s likely problem
- offer conversation, not immediate sale
- lead with architecture / technical leadership
- mention technologies only where relevant
- follow up once after 5–7 days

Do not:

- send long essays
- say “I am looking for a job”
- overuse “I can do everything”
- attach CV in the first message
- send the same message to everyone without context
- pretend to have a large company or team
- invent clients, metrics, or testimonials
